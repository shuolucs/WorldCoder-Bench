# Development Rubric Examples

This directory exposes five representative SIG/behavioral-contract rubrics
for evaluator integration and format inspection:

- `P01_bouncing_balls`
- `P02_block_tower_physics`
- `P03_double_pendulum`
- `P07_sph_fluid`
- `P11_globe_bindatamap`

Each `rubric.json` is byte-identical to the matching
`data/tasks/hf_snapshot_1799/<task-id>/icg.json`. This is an example subset, not
a claim that a separately verified 200-task WorldCoder-Dev manifest or
reference-trace release is present.
